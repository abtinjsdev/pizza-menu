# Fast React Pizza Co. — Website Description

Fast React Pizza Co. is a modern pizza restaurant website developed with **React.js**. It features a simple, clean, and user-friendly interface designed to showcase the restaurant's pizza menu and provide customers with essential information about available products and ordering options.

The website dynamically displays a collection of pizzas using reusable React components and JavaScript array methods. Each pizza includes its name, ingredients, price, and product image. The application also handles product availability by identifying sold-out items and visually distinguishing them from available products.

The website includes several key sections:

- **Header:** Introduces the restaurant with its brand name.
- **Menu:** Dynamically renders pizza items from a JavaScript data array using the `.map()` method.
- **Pizza Cards:** Display individual pizza information, including images, ingredients, prices, and availability status.
- **Footer:** Dynamically checks the current time and determines whether the restaurant is open.
- **Ordering Section:** Displays an ordering message and an order button when the restaurant is open.

### Technologies Used

- React.js
- JavaScript (ES6+)
- JSX
- HTML5
- CSS3

### Key Development Concepts

This project demonstrates practical knowledge of React fundamentals, including functional components, component composition, props, conditional rendering, JavaScript array mapping, destructuring, and dynamic content rendering.

**Fast React Pizza Co.** was developed as a practical project to strengthen my understanding of React and build a foundation for developing more advanced, component-based web applications.
