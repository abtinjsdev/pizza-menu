A simple pizza restaurant menu built with React. This project demonstrates React fundamentals, including functional components, props, rendering lists with the map() method, JavaScript objects and arrays, and dynamic content based on the current time.

**Features:**

- Dynamic pizza menu generated from an array of objects.
- Reusable Pizza components.
- Props for passing pizza information.
- Dynamic restaurant opening status.
- Conditional data handling for sold-out pizzas.

**Tech Stack:** React, JavaScript, HTML, CSS.
